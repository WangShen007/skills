# Skill Map (Personal Management)

## Domain -> Skill Mapping

- Goals:
  - `goal-tracking`: progress, risk, stalled goals
  - `goal-setter`: define/refine SMART goals
- Time:
  - `daily`: day-level plan and review
  - `weekly`: weekly reflection and planning
  - `time-blocker`: calendar blocks
  - `eisenhower-matrix`: priority sorting
- Projects & Tasks:
  - `project-manager`: milestone and project orchestration
  - `task-management`: TASKS.md action tracking
- Relationships:
  - `one-on-ones`: structured 1:1 prep and follow-up
  - `partner-text-coach`: sensitive text communication
- Health:
  - `health-coach`: wellness recommendations
  - `fitness-coach`: training schedule
  - `goal-analyzer`: health goal diagnostics
  - `habit-tracker`: habit check-in and streaks

## Suggested Cadence

- Daily:
  - morning: daily + time-blocker
  - evening: task-management + habit-tracker
- Weekly:
  - weekend: weekly + goal-tracking + project-manager
- Monthly:
  - month-end: goal-setter + goal-tracking + finance/health review

## Quick Prompts

- "给我今天的一体化计划，包含时间块、项目推进、健康底线和关系跟进。"
- "给我本周规划：3个重点、项目里程碑、1:1准备和运动安排。"
- "做本月规划：目标拆解、每周节奏、关键风险和兜底方案。"
